# 🌐 Avinash's Portfolio

A dynamic, responsive, and modern developer portfolio built with **Next.js**, **Framer Motion**, and **Tailwind CSS**. Designed to showcase my work, skills, and provide easy ways to get in touch.

## ✨ Features

- 📄 Dynamic project showcase with images, descriptions, and tech stack
- 📬 Fully functional contact form with form validation and toast notifications
- 💡 Smooth animations using Framer Motion
- 🎨 Tailwind CSS for fast, modern UI styling
- 🔗 Integrated resume download + external project/demo links
- 📱 Fully responsive layout

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- npm / yarn

### Installation

```bash
git clone https://github.com/yavinash-cloud/my-portfolio.git
cd portfolio
npm install
npm run dev
```
